# 水槽観賞アプリ

HTML・CSS・JavaScriptだけで動作する、落ち着いた雰囲気の水槽観賞アプリです。外部ライブラリやCDNを使っていないため、インターネット接続がない環境でも `index.html` を開くだけで起動できます。

## 起動方法

1. `aquarium-viewer` フォルダを開きます。
2. `index.html` を Chrome または Edge で開きます。
   - ファイルをダブルクリックしても起動できます。
   - ローカルファイルとして動作するため、サーバー起動は不要です。

## 操作方法

- **餌やり**: 水槽内をクリックすると、その位置から餌がゆっくり沈みます。近くの魚は餌へ集まり、接触すると餌を食べます。
- **魚の数**: スライダーで魚の数を変更できます。
- **泡の量**: スライダーで泡の量を変更できます。
- **魚の名前を表示**: チェックを入れると「ごんべ」「ゾロカンス」「ミレス」などの名前が魚の上に表示されます。
- **時間帯**: `自動`、`昼`、`夕方`、`夜`を切り替えられます。自動ではパソコンの現在時刻に合わせて表示が変わります。
- **餌を一括投入**: 複数の餌をまとめて投入します。
- **全画面表示**: ブラウザの全画面表示を開始・終了します。
- **操作パネルを隠す**: 観賞に集中できるよう、操作パネルを非表示にします。右上の「操作パネル」ボタンで再表示できます。

設定は `localStorage` に保存されるため、再読み込み後も前回の状態が維持されます。

## ファイル構成

```text
aquarium-viewer/
├── index.html   # アプリの画面構造
├── style.css    # レイアウト、操作パネル、レスポンシブ設定
├── script.js    # Canvas描画、魚・泡・餌・設定保存の処理
└── README.md    # この説明ファイル
```

## 実装メモ

- 描画には `<canvas>` と `requestAnimationFrame` を使用しています。
- 魚、泡、餌はクラスに分け、役割ごとに処理を整理しています。
- 餌は最大数を制限し、大量クリック時に古い餌から削除して負荷を抑えます。
- 画面サイズ変更時はキャンバスを再計算し、水槽の比率が崩れにくいようにしています。

- スクリーンショット保存機能
- 餌の種類による魚の反応差
