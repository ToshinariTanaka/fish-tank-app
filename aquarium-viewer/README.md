# 水槽観賞アプリ

HTML・CSS・JavaScriptだけで動作する、落ち着いた雰囲気の水槽観賞アプリです。外部ライブラリやCDNを使っていないため、インターネット接続がない環境でも `index.html` を開くだけで起動できます。

## 起動方法

1. `aquarium-viewer` フォルダを開きます。
2. `index.html` を Chrome または Edge で開きます。
   - ファイルをダブルクリックしても起動できます。
   - ローカルファイルとして動作するため、サーバー起動は不要です。

## 操作方法

- **餌やり**: 水槽内をクリックすると、その位置から餌がゆっくり沈みます。近くの魚は餌へ集まり、接触すると餌を食べます。
- **魚の数**: スライダーで魚の数を変更できます。
- **泡の量**: スライダーで泡の量を変更できます。
- **魚の名前を表示**: チェックを入れると「ごんべ」「ゾロカンス」「ミレス」などの名前が魚の上に表示されます。
- **時間帯**: `自動`、`昼`、`夕方`、`夜`を切り替えられます。自動ではパソコンの現在時刻に合わせて表示が変わります。
- **餌を一括投入**: 複数の餌をまとめて投入します。
- **全画面表示**: ブラウザの全画面表示を開始・終了します。
- **操作パネルを隠す**: 観賞に集中できるよう、操作パネルを非表示にします。右上の「操作パネル」ボタンで再表示できます。

設定は `localStorage` に保存されるため、再読み込み後も前回の状態が維持されます。

## 魚の種類

魚には、このアプリ用に生成した写真風の透過 WebP を使用しています。画像はすべて `assets/fish/` に同梱しています。

| 魚種 | 水槽での見分け方 | 画像 |
| --- | --- | --- |
| 金魚型 | 金色の鱗、ふっくらした胴、大きく開いた橙色の尾びれ | `goldfish.webp` |
| エンゼルフィッシュ型 | 銀色の体に黒い縦縞、上下に伸びる長いひれ | `angelfish.webp` |
| 小魚型 | 細身で、体の横に光る水色と赤の帯 | `minnow.webp` |
| フグ型 | 黄緑の背に黒い斑点、白く丸い腹と短い尾 | `puffer.webp` |
| ナマズ型 | 茶褐色の横長の体と口元の長いひげ。底に近い層を泳ぐ | `catfish.webp` |

魚は尾を2〜3回振って進み、そのあと尾を休めて惰性で泳ぎます。魚ごとに滑走する長さと減速のしかたが異なります。方向転換するときは、弧を描きながら体の見かけの幅が次第に細くなり、反対側へ向きます。

- **ごんべ**は大きな尾を振って前へ進み、尾を広げて長めに滑走します。ゆっくり向きを変えるのが特徴です。
- **ゾロカンス**は銀青色の専用画像（`zorokansu.webp`）を使います。餌を見つけるといったん減速し、鼻先を餌に向けてから一気に加速します。
- **ミレス**は中層でときどき泳ぎを止め、上下の長いひれを小さく揺らしながら数秒間その場に留まります。近くに餌が来ると再び泳ぎ出します。

金魚とエンゼルフィッシュは右向きの姿を7コマ、他の魚は3コマ収録しています。左へ泳ぐと魚だけが反転し、名前はどちらを向いてもそのまま読めます。泳ぎ方の計算と画像の表示はブラウザ内で行います。

## ファイル構成

```text
aquarium-viewer/
├── index.html   # アプリの画面構造
├── style.css    # レイアウト、操作パネル、レスポンシブ設定
├── script.js    # Canvas描画、魚・泡・餌・設定保存の処理
├── assets/fish/ # 5魚種とゾロカンス専用の透過 WebP
└── README.md    # この説明ファイル
```

## 実装メモ

- 起動時に各画像を一度ずつ読み込みます。画像が欠損・破損している場合は、該当する魚だけを従来の図形で表示します。
- 描画には `<canvas>` と `requestAnimationFrame` を使用しています。
- 魚、泡、餌はクラスに分け、役割ごとに処理を整理しています。
- 餌は最大数を制限し、大量クリック時に古い餌から削除して負荷を抑えます。
- 画面サイズ変更時はキャンバスを再計算し、水槽の比率が崩れにくいようにしています。
