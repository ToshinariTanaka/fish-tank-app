## 今回やったこと

- 既存の `aquarium-viewer` アプリを直接改良し、Canvas描画のみで金魚型、エンゼルフィッシュ型、小魚型、フグ型、ナマズ型の5種類の魚種を追加しました。
- `FISH_TYPES` を色だけでなく、shape、色、サイズ、速度、遊泳深度、上下動、餌追跡倍率を持つ設定構造へ拡張しました。
- ごんべ、ゾロカンス、ミレスに名前専用の魚種・速度・餌反応設定を追加しました。
- Fishクラスの描画処理を魚種別メソッドへ分割し、魚の左右反転、目の進行方向、名前表示の可読性、端での折り返し、巡航速度復帰を維持しました。
- `aquarium-viewer/README.md` に5種類の魚種と名前専用設定の説明を追記しました。

## 変更ファイル

- `aquarium-viewer/script.js`
- `aquarium-viewer/README.md`
- `docs/codex_report.md`

## テスト結果

- `node --check aquarium-viewer/script.js` に成功しました。
- `node /tmp/validate-fish-species.js` に成功しました。5種類のshape、ごんべ・ゾロカンス・ミレスの専用設定、全魚の巡航速度・向き、餌消失後の巡航速度復帰、左右端反転、ナマズの下層配置を確認しました。
